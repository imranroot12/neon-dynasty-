The package contains original Neon Dynasty SVG artwork under `web/neon-dynasty/static/neon-dynasty/assets/` and original development audio tones.

The package also retains Stake/Engine sample assets required by the current cluster application. These are **quarantined as non-approval assets** and must be replaced before submission. No approval claim is made until the sample assets have been removed from the runtime asset graph and the app has been built successfully with only approved original assets plus allowed Engine infrastructure assets.
